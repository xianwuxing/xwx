课堂实时翻译工具

把课堂说的每一句话,
实时转写、翻译、总结。

面向课堂场景的语音转写与翻译工具。听到什么就转写什么,同步翻译成你需要的语言, AI 边听边总结要点。网页打开即用,或安装 Windows 桌面客户端。

在线使用 → 下载 Windows 客户端

网页版无需安装,打开即用 · 桌面版一键安装,离线打开也能启动

核心能力

实时语音转写

说话即转写,支持中/英/日/韩/法/德/西/俄等多语言识别。

同步翻译

识别的同时自动翻译成目标语言,转写与译文逐条对照展示。

AI 总结实时跟随

录制过程中总结持续刷新,结束时自动生成一份完整要点总结。

一键本地保存

结束录制自动导出转写、翻译与总结为 .md / .json 文件,方便后续整理。

三步开始使用

1

打开或安装

直接打开网页版,或下载 Windows 客户端安装。

2

(可选)配置 AI

不填 Key 用免费识别;填入 OpenAI Key 后识别与总结准确率更高。

3

开始录制

点击录制按钮,课堂内容实时转写、翻译、总结,结束时自动保存。
